JNTUK R23 · PROJECT TRACEABILITY

How the curriculum concepts become working product features

The supplied problem statement explicitly names DMGT, ADSA, OOPJ and Python. The supporting cards below explain the additional Java, data, web and finance concepts used to turn those academic ideas into a complete application.

REVIEW READY
01

DMGT · Discrete Mathematics & Graph Theory

Core idea: represent buyer constraints as sets and combine them with intersection.

  • Locality set
  • Price-range set from the AVL index
  • Size set
  • Optional amenity/property-type sets
  • Final result = intersection of active constraints
The live search screen exposes the exact AND logic in the search flow.
02

ADSA · Advanced Data Structures & Algorithm Analysis

Core idea: keep a balanced price index so range queries do not require a full linear scan.

  • AVL insertion and rotations
  • Balance factor and height
  • Separate BUY and RENT indexes
  • Price-range traversal
  • Complexity target: O(log n) search on the balanced tree
The dashboard exposes AVL node count, height and range-search behavior.
03

OOPJ / OOPS · Object-Oriented Programming Through JAVA

Core idea: model real-estate listings and marketplace roles as reusable objects.

  • Listing abstraction
  • ResidentialListing / CommercialListing inheritance
  • Encapsulation of property data
  • Polymorphic listing behavior
  • Role-based Buyer and Seller workflows
The UI roles map directly to the Java object model.
04

Java · Application & API Engineering

Core idea: connect the algorithms to an executable marketplace service.

  • HTTP server and REST-style endpoints
  • Authentication and session handling
  • Search, property and inquiry APIs
  • Buyer–seller messaging
  • Persistent marketplace state
Java is the integration layer that turns the academic algorithms into an executable product.
05

Python Programming · Price Intelligence

Core idea: estimate a fair BUY price from listing features.

  • CSV input/output
  • Area features
  • Locality encoding
  • Amenity count
  • Regularized multiple linear regression
Java exports listing data → Python estimates → Java reads predictions and flags price position.
06

Data Management & Persistence

Project mapping: store accounts, listings, inquiries, messages, site visits and offers so workflows survive page refreshes and restarts.

  • Buyer and Seller records
  • Seller-owned listings
  • Inquiry/message threads
  • Favorites, offers and site visits
  • Persistent file-backed marketplace state
This is a supporting implementation area, not an additional claim about the supplied problem statement.
07

Web & API Integration

Project mapping: the browser is a role-based product UI over the Java service.

  • Role-first authentication
  • Buyer workspace and Seller workspace
  • Async search and live market calls
  • Map and chart components
  • Form-driven marketplace actions
Each action can be traced from button → API → stored result → visible state.
08

Finance & Decision Support

Project mapping: use price estimates and affordability calculations to help a buyer make an informed decision.

  • EMI planning
  • Loan-to-value view
  • Housing load estimate
  • Price-vs-estimate signals
  • Transparent recommendation factors
Supporting application capability; not presented as an official course requirement.
09

Listing Architecture · Real-World Marketplace Model

Project mapping: connect the academic search engine to a realistic property lifecycle.

  • Seller publishes listing
  • Buyer discovers and compares
  • Buyer sends enquiry
  • Seller replies or proposes a site visit/offer
  • Buyer tracks the conversation
This is the project's real-world extension beyond the original buyer-preference statement.

ABOUT ESTATELENS

What this project does

EstateLens helps buyers discover suitable properties and helps sellers publish and manage listings. The academic engine combines mathematical set operations, an ADSA AVL price index, OOPJ Java classes, Python fair-price estimation and a listing-to-inquiry marketplace workflow.

DMGTSet intersection for buyer preferencesADSAAVL price-range indexingOOPJ / OOPSJava inheritance & polymorphismJAVABackend, APIs, authentication & persistencePYTHONRegression, CSV processing & price estimationLISTINGProperty model, seller publishing & buyer matching

02Post property, price, location & amenities
03Appear in buyer search and comparison
04Receive buyer inquiries and notifications
05Manage verification and listing quality signals
06Handle site visits, offers and buyer conversations
