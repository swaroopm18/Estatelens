# JNTUK R23 mapping note

The supplied problem statement names these subjects as DMGT, ADSA, OOPJ and Python.

For the dashboard wording, the project uses the standard R23 course names visible in the accessible JNTUK-aligned CSE R23 syllabus source:

- Discrete Mathematics & Graph Theory (DMGT)
- Advanced Data Structures & Algorithm Analysis (ADSA)
- Object-Oriented Programming Through JAVA (OOPJ)
- Python Programming

The project does **not** claim that every implementation detail is prescribed by the regulation. Instead, the dashboard maps each named subject to the concrete concept used in this project.
