# Comparison, Market Intelligence, and Trust Focus

## Comparison
- Comparison uses only the current search results selected by the buyer.
- Up to three current properties can be compared.
- Stale selections are cleared when the search result set changes.
- Recommendation scores are calculated separately for each selected property.

## Market Intelligence
When a comparison selection exists, Market Intelligence is focused on those selected properties and reports:
- average asking price
- average price gap versus Python estimate
- best profile fit
- locality signal
- map concentration
- trend direction
- selected comparison context

Without a comparison selection, Market Intelligence uses the current search result set.

## Trust & Deals
Trust & Deals uses the same selected comparison set when one exists. Previous selections are cleared when they are no longer part of the current search results.

## Academic dataset
The academic reference dataset now includes additional Visakhapatnam-area regions: Seethammadhara, Akkayyapalem, Kancharapalem, Gajuwaka, Pendurthi, and Sujatha Nagar, with both BUY and RENT reference listings.
